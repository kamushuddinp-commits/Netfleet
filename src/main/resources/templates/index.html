How Many-to-Many Mapping is Modeled

Built strictly to demonstrate object-oriented design, heap reference passing, and dynamic array collections in Java.

1. Dynamic Array Storage

Both Student and Course maintain dynamic ArrayList<Enrollment> collections. Courses grow dynamically as new learners join, and students can register for as many courses as they wish without static array limits.

private final ArrayList<Enrollment> enrollments = new ArrayList<>();
2. Object Reference Passing

Instead of cloning student and course data, the associative Enrollment entity accepts live object references directly in heap memory: new Enrollment(id, studentRef, courseRef). Modifying an instructor immediately updates the student's view.

this.student = student; // Reference passing
this.course = course;
3. Bidirectional M:N ER Linkage

Resolves the classic Many-to-Many ER dilemma. From any student, navigate student.getEnrolledCourses(). From any course, navigate course.getEnrolledStudents() with full duplicate prevention and safe reference cleanup.

student.addEnrollment(enr);
course.addEnrollment(enr);
